# Semantics

## HTML meaning and native controls

Use the WHATWG HTML Living Standard and web.dev semantic HTML pointers for element meaning and native controls. Follow Accessibility for interaction and accessibility requirements.

## Structured and linked data

Use the Schema.org /docs/ catalog for vocabulary modeling and the JSON-LD 1.1 W3C Recommendation pointer for linked-data syntax. This catalog excludes the complete Schema.org type/property vocabulary.

## Content and domain models

Use the Contentstack content-modeling pointer as product-specific guidance, then follow the target CMS hub. Verify applicability to the consuming stack.

## Semantic search

Use the Optimizely Graph pointer for its experimental semantic-search feature. Confirm current availability and limitations for the target Graph deployment; this is separate from HTML and structured-data semantics.
