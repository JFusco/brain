# Living visual Brain

The visual Brain represents reusable knowledge and official reference metadata. It never loads wiki project history. Markdown and Git remain authoritative; generated nodes and links are rebuildable. A committed local main snapshot keeps working edits from appearing as published knowledge.

The loopback interface uses 3d-force-graph, stable domain anchors and a three-dimensional star system of decorative stellar clusters and independently inclined orbits. Search lives in the bottom-right dock, and animated dials display actual recorded usage. Indexed knowledge counts remain separate from usage. Motion has no manual pause control; operating-system reduced motion and hidden-tab rendering protections remain. Ranking selects evidence; shortest paths explain explicit relationships and do not require reading intermediaries. Browser notes render formatted Markdown using allowlisted DOM elements; embedded HTML stays inert. Selecting a node opens a zoomed connected-star view with actual graph edges and moving relationship pulses; the overview also displays edges between visible stars. Project manifest context is CLI-only.

Private SQLite activity records known IDs, event types, timestamps and snapshots. Reported reads/citations are assertions, not monitoring. Counts span content revisions, reflect recorded activity and do not affect evidence authority. Sessions expire after 24 hours; daily aggregates survive pruning of 30-day detail. Counts use New York calendar dates.

Health and coverage reuse existing source signals without inventing validation or lessons. The source remains usable if metrics fail. Code rollback must preserve local activity data. Future shared/cloud activity is deferred.

Evidence: https://github.com/JFusco/brain/issues/98 and `scripts/lib/visual-brain/`.

Shared CLI activity from other projects drives the same local viewer: electrical lookup scan/results, mint reads, warm citations and violet pending intake. Pending-capture counts are grouped by domain in a separate layer; they are not published graph nodes or retrieval evidence. Capture contents and origins are not exposed. Labels are reserved for the focused view.

Capture arrivals have an independent eight-second effect: violet stars converge on the pending ring, diffuse clouds bloom and a wave expands. It remains visible in focused mode without closing the note or replacing lookup feedback. Reduced motion uses static stars/clouds; visible-frame timing holds the effect while hidden. A fixed pool of decorative particles bounds repeated captures without adding graph nodes or exposing capture details.
