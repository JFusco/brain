# Office knowledge interfaces

The Office consumes versioned read-only CLI contracts rather than coupling its private evidence store to the Brain viewer. The scanner returns value-free metadata after acquisition. Published guidance is pinned to committed snapshots with exact content hashes; inbox candidates and worktree edits are excluded.

Capture-to-note lineage is an explicit operator-supplied incorporation map verified against the merged commit. Historical acceptance without a map remains unknown. A path appearing in a publication is insufficient evidence of incorporation.

See [the interface contract](../../docs/office-interfaces.md) and [the implementation record](../journal/2026-11-09-office-interfaces.md). Source code and repository verification remain authoritative for current behavior.
