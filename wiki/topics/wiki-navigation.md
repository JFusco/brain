# Wiki navigation

The wiki retains its Markdown graph, deterministic weighted routes and integrity checks. The optional Sigma browser viewer and its server were removed because the visual Brain represents knowledge rather than project history. Browser-only routing code is removed; command-line navigation remains authoritative.

Evidence: https://github.com/JFusco/brain/issues/97 and `scripts/wiki/navigate.cjs`.
