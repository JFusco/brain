# Tooling knowledge domain

[Issue 173](https://github.com/JFusco/brain/issues/173) adds `tooling` to the configured domains, immediately before `_unsorted`, with a capture keyword entry after `semantics`. The new hub routes build configuration, test runners, component workshops, linting, package management and monorepo questions and links Frontend, TypeScript, React and Next.js. It starts with no curated notes and no official catalogs.

This is the first delivery of the source-gap plan: the registry validator rejects sources for unconfigured domains, so the domain must merge before Vite, Vitest, Storybook, Testing Library, ESLint, pnpm or Turborepo can be registered. The README Coverage watch list names their hosts as unregistered candidates; each source is verified by retrieval and local sync in its own change. Existing backlog records keep their assigned domains. See [official reference expansion](../topics/official-reference-expansion.md).
