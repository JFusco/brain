# Thin the CLI entry points

[Issue 159](https://github.com/JFusco/brain/issues/159) is phase 4 of the cleanup. The Root scripts now only parse arguments, dispatch and report.

**The `brain.mjs` command table.** Its separate help text, allowed-flag table, precedence-heavy "mutating" expression and if-chain dispatcher became one declarative table in `tree/cli/{commands,visual-commands,knowledge-commands,maintenance-commands}`. Each command declares:
- its options;
- its usage lines;
- whether it mutates private state, and so takes the lock;
- its handler or per-subcommand handlers.

Help is generated from the table, so it can no longer drift from the accepted options. Handlers that take no arguments are wrapped so they are still called without any. Visual commands still load on demand, through explicit `import()` specifiers that the import checks can verify.

**Weekly reference health.** Split into:
- `branch/hosted/previous-state`, whose link-record filter `keepLink` is now pure;
- `branch/hosted/issue-body`, issue rendering with an explicit run context;
- `tree/hosted/{deliver,weekly}`;
- a root that only checks the trusted run and writes the step summary.

**Gitleaks install data.** The download hosts, checksum-file parsing and archive selection are shared by `setup.mjs` and `hosted/setup.mjs` through `branch/platform/gitleaks`. Their distinct error messages are kept.

Verification:
- `brain.mjs --help` output is byte-identical.
- A replay of 52 CLI invocations is identical, covering unknown commands and subcommands for every command, missing values, duplicate and unsupported options, help variants, commands that ignore subcommands, and argument validation errors.
- The read-only command baseline is unchanged, apart from `check`'s scanned-file count.
- The local setup download path ran end to end in a throwaway clone.
- New tests:
  - the CLI contract is table-driven: help lists every command, the README documents every command, the lock rules hold;
  - weekly issue rendering, previous-state filtering and checksum parsing.
- `pnpm run verify:ci` passed.
