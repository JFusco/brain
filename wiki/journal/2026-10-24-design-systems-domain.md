# Design-systems knowledge domain

[Issue 175](https://github.com/JFusco/brain/issues/175) adds `design-systems` to the configured domains after `tooling`, with a capture keyword entry after the tooling keywords. The hub routes design token, design-to-code and component library questions, links Frontend, Accessibility and Tailwind, and states that existing project design-system decisions take precedence. It starts with no curated notes and no official catalogs.

The registry validator rejects sources for unconfigured domains, so this domain merges before the Design Tokens Community Group format or Figma developer documentation can be registered. The README Coverage watch list names www.designtokens.org and developers.figma.com as unregistered candidates; the legacy design-tokens.github.io format URL and figma.com/developers/api both redirect to those hosts. See [official reference expansion](../topics/official-reference-expansion.md).
