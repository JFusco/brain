# pnpm documentation catalog

[Issue 203](https://github.com/JFusco/brain/issues/203) registers `pnpm-docs`, a sitemap collection on `pnpm.io`. `pnpm.io/llms.txt` returned 404 and pages have no `.md` variants. The single sitemap held 484 locations; the source includes the root docs and excludes the versioned `/10.x` and `/11.x` trees, the blog, `/r/` redirect shortcuts and the donation and logo pages. Local `official sync` read one index and catalogued 170 pages: 89 CLI command pages, 10 settings pages, 19 pages for the experimental pnpr registry, a separately versioned docs set and 52 other root pages, including the site homepage, installation, workspaces, catalogs and supply-chain security.

The docs search version reported 12.x for the root docs at registration. Content review found that `/10.x` serves separate versioned docs while the `/11.x` sitemap entries redirect to the root docs. Brain pins pnpm 10, whose versioned docs are not catalogued, so readers confirm the project's `packageManager` version. Tooling had no curated notes; the unscoped `browser verification accessibility` lookup kept both curated notes at positions 1 and 3. The `pnpm/pnpm.io` repository is MIT-licensed; the catalog stores links and metadata only. See [official reference expansion](../topics/official-reference-expansion.md).
