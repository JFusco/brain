# axe-core rule help catalog

[Issue 189](https://github.com/JFusco/brain/issues/189) registers `deque-axe-rules`, a static HTML collection read from `dequeuniversity.com/rules/axe/4.14` and limited to `/rules/axe/4.14/`. Local `official sync` read one index and catalogued 105 rule help pages, titled by rule ID. A `color contrast` lookup in Accessibility now returns `color-contrast` and `color-contrast-enhanced` first.

axe-core v4.14.0 was the latest stable release at registration. The repository's single rule-descriptions file and its API, contributor and example docs were left out. Deque's pages carry no open license, so the catalog stores links and metadata only. Accessibility had no curated notes, so its lookups gave no retention evidence; the unscoped `browser verification accessibility` lookup kept both curated notes at positions 1 and 3. See [official reference expansion](../topics/official-reference-expansion.md).
