# Figma developer documentation catalog

[Issue 193](https://github.com/JFusco/brain/issues/193) registers `figma-developer-docs`, a sitemap collection on `developers.figma.com`. The single sitemap held 863 locations; the source keeps `/docs/rest-api/`, `/docs/plugins/` and `/docs/code-connect/` and excludes the 161 plugin changelog pages. Local `official sync` read one index and catalogued 570 pages: 488 Plugin API guide and reference pages, 63 REST API pages and 19 Code Connect pages.

Pages have no Markdown variants, so focused excerpts read HTML. Before and after the sync, the unscoped `component meaning Code Connect` lookup kept the Frontend design-context note at position 1; Design systems had no curated notes to retain. Figma's documentation carries no open license, so the catalog stores links and metadata only. See [official reference expansion](../topics/official-reference-expansion.md).
