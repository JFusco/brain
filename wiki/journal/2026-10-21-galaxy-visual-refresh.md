# Replace the anatomical Brain with a galaxy

Joe requested a circular space-like interface instead of the anatomical silhouette, giant nodes, left-side marketing copy and pause control. The scene now uses a shifting spiral dust field, small glowing knowledge points, background stars and orbital rings. Search and filters occupy the bottom-right dock. Coverage, recent activity and frequently used items remain available through Activity details.

Metric dials rotate decoratively, animate actual value changes and flash when recorded counts change. Indexed note and reference totals are shown separately; usage starts at zero and is not populated with demonstration activity. Reduced motion and hidden-tab rendering protections remain, without a manual pause toggle. Backend retrieval, session rules and private SQLite storage are unchanged.

Local evidence: frontend build passed with the existing large-chunk advisory. A real browser search returned ranked sources from the new dock and updated the displayed usage totals. This is focused local presentation evidence, not a deployment or broad audit. No tests, fixtures or review agents were added. Follow-up changes are local and uncommitted.

Affected sources: `web/brain/` and README. Prior architecture remains in [Living visual Brain](../topics/visual-brain.md).
