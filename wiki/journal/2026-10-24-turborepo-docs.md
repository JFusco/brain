# Turborepo documentation catalog

[Issue 205](https://github.com/JFusco/brain/issues/205) registers `turborepo-docs`, a Markdown-index collection read from `turborepo.dev/llms.txt` and limited to `/docs`. Local `official sync` read one index and catalogued 110 pages with their published titles: 41 guides, 29 reference pages, 12 crafting-your-repository pages, 8 Remote Cache API pages, 5 each for getting started, core concepts and error messages, and the docs index and support pages. The sitemap lists the same pages with path-only titles.

`fetchSuffix: ".md"` keeps reader links on HTML pages while excerpts read Markdown, including `docs/index.md`. npm reported turbo 2.11.10 as `latest` at registration. This is the last Tooling source in the plan: Vite, Vitest, Storybook, Testing Library, ESLint, pnpm and Turborepo are now catalogued. Tooling still had no curated notes; the unscoped `browser verification accessibility` lookup kept both curated notes at positions 1 and 3. The `vercel/turborepo` repository is MIT-licensed; the catalog stores links and metadata only. See [official reference expansion](../topics/official-reference-expansion.md).
