# Figma MCP server documentation

[Issue 212](https://github.com/JFusco/brain/issues/212) extends `figma-developer-docs` with `/docs/figma-mcp-server/`, which the [Figma registration](2026-10-24-figma-docs.md) had left out of scope. Its pages cover remote and local server installation, tools and prompts, Code Connect integration, custom rules, writing to the canvas, rate limits and troubleshooting.

A local `official sync figma-developer-docs` catalogued 594 pages: the previous 570, unchanged, plus 24 MCP server pages titled from their paths. A design-systems `Figma MCP server tools` lookup now returns MCP server pages. Design systems has no curated notes, so its three fixed queries give no retention evidence and their top five were unchanged. Unscoped and Frontend `component meaning Code Connect` kept the design-component context note first, and the other Frontend comparisons kept their notes first. The catalog lists documentation links only; Brain installs or configures no MCP server. See [official reference expansion](../topics/official-reference-expansion.md).
