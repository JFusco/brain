# Vite documentation catalog

[Issue 183](https://github.com/JFusco/brain/issues/183) registers `vite-docs`, a sitemap collection on `vite.dev` limited to the guide, config reference and breaking-changes sections. Local `official sync` read one index and catalogued 38 pages: 24 guide, 8 config and 6 breaking-change pages. `fetchSuffix: ".md"` keeps reader links on the HTML pages while focused excerpts use the Markdown versions.

The Tooling hub now says catalogs are rolling and asks readers to confirm installed tool versions. The domain had no curated notes, so its three lookups gave no retention evidence; the unscoped `browser verification accessibility` lookup kept both curated notes at positions 1 and 3. The `vitejs/vite` repository is MIT-licensed; the catalog stores links and metadata only. See [official reference expansion](../topics/official-reference-expansion.md).
