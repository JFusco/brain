# OpenAI model and agent guidance

Issue [257](https://github.com/JFusco/brain/issues/257) adds one bounded OpenAI official collection and two Tooling playbooks for current general-purpose models/reasoning and skill/reference/rule authoring. Provider-specific facts remain separate from the Claude notes, with cross-links for the corresponding decisions.

Local `official sync openai-agent-docs` retrieved one index and generated 237 links with no source failures. Explicit model and ChatGPT/Codex references were retrieved before registration; an unavailable best-practices index target was omitted and its discovery failure retained privately. Catalog retrieval does not establish performance or runtime skill compatibility. [Official reference expansion](../topics/official-reference-expansion.md#openai-model-and-agent-guidance) records the scope and limits.
