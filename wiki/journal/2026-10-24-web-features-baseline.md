# Web Platform Baseline documentation

[Issue 181](https://github.com/JFusco/brain/issues/181) registers `web-features-baseline`, a repository source limited to four exact files in `web-platform-dx/web-features`: `docs/baseline.md`, the repository README and the `web-features` and `compute-baseline` package READMEs. Local `official sync` pinned commit `2c24bbfc45cfb8b7fea90bd1618b0ad5027bec5d` with four docs and no skills.

The existing MDN catalog already covers the Baseline glossary pages, so this source adds only the normative status definition and package documentation; feature data files stay out. Baseline remains browser-support evidence, separate from accessibility, usability or a project's browser-support acceptance. Before and after the sync, the three Frontend lookups and the unscoped `browser verification accessibility` lookup kept every curated note at its position. Two document titles keep the Markdown link syntax of their upstream headings, a cosmetic limit of heading-derived titles. See [official reference expansion](../topics/official-reference-expansion.md).
