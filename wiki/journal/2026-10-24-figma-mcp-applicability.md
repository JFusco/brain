# Figma MCP applicability caveat

[Issue 221](https://github.com/JFusco/brain/issues/221) completes the [Figma MCP server catalog](2026-10-24-figma-mcp-docs.md) change. The `figma-developer-docs` applicability now asks readers to confirm the MCP server mode and client before applying MCP guidance. Figma's installation pages separate the recommended remote server from the desktop server, which requires the Figma desktop app, a Dev or Full seat on certain plans, and does not support writing to the canvas. A local `official sync figma-developer-docs` left the 594-page catalog unchanged. See [official reference expansion](../topics/official-reference-expansion.md).
